Logic Gate Defender

Defend your base against incoming signals using boolean logic! Each enemy carries two true/false signals.

How to Play

  1. Select a Gate: Click a logic gate button at the bottom (e.g. AND).
  2. Place it: Click on a grey "SLOT" in the path to spend Bits and build the gate.
  3. Defend: Gates evaluate enemy signals and destroy them if the logic rule is satisfied.

Gate Rules

  • AND: Destroys if both are True (TT)
  • OR: Destroys if at least one is True
  • NOR: Destroys if both are False (FF)
  • XOR: Destroys if signals are different
  • NAND: Destroys unless both are True

⚠️ Overheating Warning

Gates have a durability of 3 uses! After destroying 3 enemies, a gate will break and you must build a new one.
